# Manşet APK
1. Bu klasörün içindekileri GitHub'da yeni bir depoya yükle.
2. Actions sekmesi > "APK Derle" > Run workflow.
3. Bitince (5-8 dk) Artifacts bölümünden Manset-APK'yi indir, zip'ten çıkan app-debug.apk'yı telefona kur.
Oyunu güncellemek için www/index.html dosyasını değiştirip tekrar yükle.
